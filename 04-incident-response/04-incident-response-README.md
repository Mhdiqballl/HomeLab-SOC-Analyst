# Fase 4: Incident Response

## Tujuan
Melatih proses investigasi insiden end-to-end menggunakan TheHive, dari triage alert sampai penulisan incident report resmi.

## Tools yang Digunakan
- TheHive
- Wazuh (sumber alert)

## Langkah yang Dilakukan
1. Install TheHive
2. Pilih 1 case dari Fase 3 untuk diinvestigasi penuh
3. Buat case di TheHive (timeline, IOC, root cause analysis)
4. Tulis Incident Report resmi dalam format PDF
